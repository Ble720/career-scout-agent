# Career Scout Agent: Autonomous Job Hunter & Tailoring Workspace

A smart, **Human-in-the-Loop AI assistant** built to automate the tedious parts of hunting for a job. Powered by **LangGraph**, the agent handles multi-stage workflows to scan the live web for listings, extract detailed job details using **Google Gemini 2.5 Flash**, calculate recommendation match scores directly inside **PostgreSQL (`pgvector`)**, and give you a simple **Streamlit** chat interface to review, edit, and fine-tune your application materials.
